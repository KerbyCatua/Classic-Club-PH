Global system configuration

Application-wide settings ? Authorized Super Admin only. Changes take effect after review and confirmation. Feature availability preserves role permissions and assigned-business boundaries.

Loading saved configuration?

Global preferences, security & sessions

Password length applies to new passwords; existing passwords remain valid. Failed-login attempts use a 15-minute window. Session limits apply on the next authenticated request. The report period sets the initial business report view.

Authentication & feature availability

Authentication uses the existing email and password sign-in. MFA/2FA enrollment is not required. New public accounts retain the Customer role and active state. Disabling reviews prevents new submissions and business replies; existing review history remains available.

Review application-wide changes

    Existing application constraints

    Branding: Classic Club PH. Currency: PHP. Locale: English / Philippines. Table sizes and date displays remain defined by their existing screens. Maintenance is managed by the existing Maintenance module.

    Email delivery, SSO, email verification, sensitive-action re-authentication, global notification preferences and experimental features have no configurable implementation here. Password-reset requests retain their existing administrative workflow and 60-minute validity. Support submission retains its existing contact workflow. These controls are unavailable. Administrative audit history and review before saving configuration remain required.
